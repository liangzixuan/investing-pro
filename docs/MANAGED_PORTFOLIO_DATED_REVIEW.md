# Dated Portfolio review

Implementation and acceptance are in progress. This workflow joins the existing
dated Portfolio reading to an ordered review of checks for current holdings.

## Prepare the reading

Load Portfolio explicitly and inspect its complete authored ledger. Open the
dated close review, load the supported closes and choose a date. Missing closes,
unsupported listings, raw amounts and source times remain visible. Load
Follow-ups separately with **Load Follow-ups for review**.

Select **Review held-company checks** to retain the complete dated report and
open Follow-ups. This action does not start requests, choose checks or start a
review. Prepare the existing held-company due plan, inspect its inclusions and
exclusions, choose up to five checks in order, then start the review.

## Review each chosen check

The original report remains available under **Original dated Portfolio reading**.
It keeps the full ledger, balances, close coverage, attribution and source
packets. It does not refresh as assessments change. The close date, source times
and UTC day used to assess due checks are separate.

For each check, use the existing explicit Filings controls or Research. An owned
Filings inspection keeps the captured packet. Research keeps its existing exact
listing resolution. Back returns to the chosen check and its original reading.
Write the assessment, preview citations and complete the check when appropriate.
Continue moves to the next chosen check. Source completion never advances it.

Finish retains the complete chosen order, current assessments and open/completed
statuses. Other open checks from the original eligible plan remain listed.
Finishing does not mark open checks complete or save the draft. Save Follow-ups
separately. A fresh Load is also a separate action.

## Lifetime and boundaries

The reading belongs to the loaded Portfolio and Follow-ups contexts, catalog,
session and owned navigation. Unrelated navigation, resource replacement, file
activity or a forbidden check change retires it. Authored result and completion
changes within the admitted review keep it. Save or fresh Load ends this reading;
return to Portfolio to prepare a new one.

This adds no provider, financial calculation, security coverage, background
monitor, persistence resource or automatic financial recommendation. It reuses
the [complete Portfolio report](MANAGED_PORTFOLIO_REVIEW_REPORT.md),
[held-company intake](MANAGED_PORTFOLIO_FOLLOWUPS_REVIEW.md) and
[review filing evidence](MANAGED_REVIEW_FILINGS.md).
