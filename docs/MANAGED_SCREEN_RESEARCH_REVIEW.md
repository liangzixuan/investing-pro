# Two-company research decision review

Keep a complete reading for each company in the current financial-screen pair.
Use the existing company Research and valuation workbench, then return to the
pair before writing the chosen company's thesis and dated check.

## Workflow

1. In Discover, run the Annual financial screen and choose two distinct company
   rows for comparison. Open either selected company's Research.
2. Review the admitted Annual packet. Load other sources explicitly when needed.
   Edit authored valuation assumptions and Calculate separately.
3. Select **Retain current company reading**. Capture keeps the complete source
   states, current note and full calculation, including raw inputs and refusals.
   It does not request a source, calculate, edit or save a resource.
4. Use owned Back to Discover. Open the other company from the retained pair.
   The single valuation editor protects its prior inputs: save them if needed,
   then use the existing explicit discard/switch action before entering the
   other company's inputs. A retained first-company reading remains unchanged.
5. Capture the second company. Inspect both complete readings in Discover,
   including different fiscal periods and independent source times. Replace a
   reading only with another explicit capture; Clear removes only retained data.
6. Open the chosen company's current Research. Add it to the Watchlist when
   needed, author its thesis and prepare a dated next check with the existing
   controls. Save Watchlist, Follow-ups and valuation inputs independently. Fresh
   Load confirms each saved resource; retained pair readings are not saved.

## Evidence and limits

Each capture keeps full listing/share-class identity and catalog digest. Price,
Annual, Interim and Filings retain their complete available packets, missing or
unsupported states, failed-refresh qualifications and original clocks. Filings
also retains its last check and refresh comparison. Fiscal periods remain
independent; the app does not rank or normalize the two companies.

The capture time records when the reading was retained. The calculation time
records the explicit Calculate action. Neither replaces source dates. Raw
assumptions and all results, sensitivity tables and model refusals stay intact.
The retained calculation has no editor authority and cannot restore inputs,
prepare a live note/check or authorize Save. Each captured report document is
kept exactly as prepared, subject to the existing whole-document limit.

## Lifetime

Owned Research and Back preserve the pair. Ordinary source refresh, note edits
and resource Save do not silently update a retained reading. Pending operations
block a new capture and retire earlier action handles. Source requests and
calculations remain explicit when reopening a company.

Changing the pair, run, criteria or cohort retires the retained reading. Foreign
company navigation, leaving Discover, catalog replacement, resource Load or
recovery, file activity and session retirement also retire it. Restoring equal
values does not revive a retired action. Reentrant replacement cannot capture
another company's evidence or move focus using an older action.
