# Portable Annual-pass comparison report

Prepare a private HTML report from the current settled Annual-pass comparison.
Inspect the complete preview, then choose **Save Annual-pass report (HTML)** on
Android or **Download Annual-pass report (HTML)** in the browser. Document delivery
is separate from Watchlist Save. Cancel keeps the prepared preview.

## Evidence and ownership

The report keeps the exact ordered listings, applied criteria, previous and
current run metadata, full raw packets, results, refusal reasons and request
attempts. Source, request, evaluation, refinement, continuation and report
preparation clocks remain distinct. Clause readouts present the stored criteria
against captured fields; they do not establish a new evaluation time or request.
Missing current evidence is never filled from a previous packet. A cancelled
dispatched request remains distinct from a row that was never attempted.

Preparation uses the existing pass owner and exact settled result. It makes no
source request, calculation, personal-resource change or online Save. It does not
require loading a Watchlist. Route, session, catalog, file, resource or result
replacement retires the document lease permanently, including equal-value
replacement. Owned Research/Back can retain the comparison; returning permits a
new report capture without reviving an old document operation.

## Document and failure behavior

The on-screen raw disclosures open on demand. The standalone HTML contains every
raw disclosure before interaction, including full previous and current runs and
the complete report payload. It has a fixed title, format and restrictive CSP,
embedded styles, and no scripts, external assets or editing controls. Authority
handles and personal-resource contents are excluded.

The filename uses the complete UTC preparation time. The complete document must
be valid UTF-8 and no larger than 8 MiB. Invalid or oversized output is refused,
never truncated. A failed write retains the report and reports failure. Cancel,
owner replacement and late delivery cannot overwrite a newer operation.
