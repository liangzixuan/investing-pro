# Saved scenarios in a Watchlist daily review

This source increment extends the existing daily review. It has not passed hosted
native or release acceptance. No new provider, formula or saved resource is added.

## Read and evaluate

Load My Watchlist, choose one to five exact listings, then start a daily review.
Preview and run Price or Filings only when needed. Source outcomes retain their
original dates and complete packets; unsupported, failed and unattempted reads
remain separate.

In **Saved scenarios for this daily review**, select **Load saved valuation
inputs**, then **Preview saved scenarios**. The preview captures the latest
confirmed collection, its version and the exact ordered group evidence. It does
not use unsaved collection entries or change an editor draft. Each listing shows
its full saved raw inputs, missing-input reason or identity refusal. Catalog,
share class and admitted issuer must match; a matching ticker alone is not enough.

Select **Evaluate saved scenarios** to evaluate the admitted entries at one
explicit action time. The existing DCF and exit-multiple calculators show all
bear, base and bull outcomes. The existing Price comparison shows all six rows,
including each refusal. An invalid latest raw close never falls back to an older
close. Missing Price does not prevent a valid authored valuation calculation.
These are saved inputs evaluated now, not historical valuation results.

The complete retained Price state remains available in its disclosure, including
failed-refresh provenance and original response clocks. Opening it renders the
full packet without clipping. Evaluation makes no source request and gives no
note, restore or check authority to these passive calculations.

## Investigate, finish and save

Use the selected company's Research control during the active daily review.
Restore saved inputs explicitly, revise and calculate in the existing workbench,
then author a note or next check using that current calculation. Back retains the
exact group reading and original group Price evidence without refetching or
recalculating it. Company source changes do not replace the group capture.

Finish keeps the complete ordered reading and removes Load, Preview, Evaluate,
clear and Inspect actions. Start another daily review, or open current company
research from My Watchlist, to make another decision. Save valuation inputs,
Watchlist and Follow-ups separately. A fresh session must Load each resource;
the transient daily reading is not saved. Unsaved drafts remain unsaved.

For an uncertain valuation save, open company Research and expand **Saved
inputs**, then use **Reconcile original valuation save**. For a conflict, Load
the latest version, compare it with the retained draft and choose **Use saved
version** or **Keep valuation draft**. Return to My Watchlist and start a new daily
review, then preview the confirmed collection again. Recovery does not evaluate
or save the daily reading.

## Ownership and checks

Preview and Evaluate require the exact committed state, group revision, confirmed
collection and source objects. Resource replacement, source work, file activity,
catalog or membership changes, foreign navigation and session retirement end the
capture. Replacing the old values cannot restore it. Owned Research and Back are
the narrow return path; Finish is passive. Subscriber reentry cannot commit a
stale action or move focus after a retired action.

Focused model, rendered action and workspace tests use invented fixtures. The
additive Android scenario chooses Class A, Class C and an unsupported third
listing, asserts partial source counts and all outcomes, opens current Research,
returns, finishes, saves all three resources and checks fresh Loads. Its Plan,
Results and Finish frames show scoped headings; full journey assertions supply
the rest of the evidence. Source compilation alone is not a device test.
