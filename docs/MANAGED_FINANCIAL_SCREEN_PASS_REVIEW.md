# Review a fresh Annual pass

Updated November 5, 2026.

Use **Preview fresh Annual pass** after a screen settles in Discover. The preview
keeps one complete previous reading and lists every selected company in request
order. It uses the current applied filters. Staged filter edits must be applied
or discarded before preparing this pass.

## Complete workflow

1. Inspect the previous results, exact listing identities, filter clauses, raw
   values, financial periods and source dates. Preview makes no source request
   and changes no shortlist, pair or personal draft.
2. Choose **Keep current screen** to cancel the preview. The original screen
   stays intact. A cancelled preview cannot run later.
3. Choose **Run reviewed fresh pass** once. It starts a new full pass through the
   existing Annual reader, with at least 20 seconds between dispatches. It clears
   the earlier shortlist and comparison pair. It does not save a personal resource.
4. Inspect every previous and current row. A repeated read can return unchanged
   evidence. A different financial period does not establish a like-for-like
   change. Missing, failed, historical and partial evidence keep their original
   meanings; unavailable values are never zero or an inferred nonmatch. Open a
   complete raw disclosure to inspect the full packet and result.
5. Choose **Cancel fresh pass** to stop queued or pending work. Completed packets
   remain. A dispatched but cancelled request is distinct from a row that was
   never attempted. Late responses cannot change the cancelled pass.
6. Use the current screen's Research action. It opens the exact current packet
   without another source request. Back retains the screen and comparison reading.
   Previous rows are passive evidence and cannot open current Research.
7. Shortlist current results explicitly. Watchlist catalog review, Save and fresh
   Load remain separate actions. **Clear pass comparison** removes the passive
   reading without undoing completed screen work.

## Ownership and clocks

The pending plan belongs to the exact run, ordered selection, criteria revision,
Discover visit, session and Watchlist resource/file state. Replacing a source or
leaving and returning does not revive old callbacks. A replacement preview
permanently retires the earlier plan. Subscribers cannot dispatch a cancelled or
superseded pass through reentrant notifications.

The controller keeps one previous snapshot and its own fresh result. It never
attaches an unrelated run, including an equal-definition run or a later
same-handle missing-read continuation. Such a change marks the old comparison as
historical. Owned Research/Back and shortlist changes preserve an unchanged run.

Run start/completion, request start/settlement, local evaluation and packet
cutoff/source completion are separate clocks. Earlier local refinement and later
continuation evaluations retain each row's actual evaluation time. The feature
does not claim that an explicit new request produces a newer filing.

The existing **Run screen** and missing-read continuation remain available.
This feature adds no provider, coverage, calculation, saved schema, background
refresh or automatic retry. Watchlist Load is not a prerequisite for a screen
that already owns a valid cohort and selection.
