# Compare Annual statements from screening

Choose two loaded results from the [financial screen](MANAGED_FINANCIAL_SCREEN.md)
to read their Annual statements together. The comparison reuses each result's
complete captured report. Selecting a company, changing statement groups and
inspecting sources make no additional Annual request.

## Choose and read

After the screen finishes, or cancellation settles, select **Compare left** and
**Compare right** on two distinct loaded results. A failed or unread result cannot
supply a report. The pair is separate from the shortlist and saved Watchlist.

The comparison shows both exact listing identities. One statement-group control
selects Income statement, Balance sheet or Cash flow for both companies. Each
table keeps its own filing dates and comparative columns. These periods can
differ; the app does not align fiscal years or infer that the companies are peers.

Values and refusals use the existing canonical statement explorer. Exact signs,
decimal amounts, actual flow periods, balance dates and historical-use limits
remain visible. Missing concepts stay unavailable. Inspect each line's original
observation references and each company's independent source context without
another source request. The two contained tables can scroll independently.

## Continue research and return

Open either company's research from its comparison card. The existing screening
source handoff supplies that exact report. Refresh remains explicit. Existing
selected-cell note tools, whole-note Preview, single-use Append, Review, Save,
recovery and per-company captured reports retain their boundaries.

Back returns to the screen's criteria, results, shortlist and selected pair.
Watchlist, Follow-ups and Portfolio drafts remain independently owned. Selecting
a comparison does not add a company, edit a note or save a record.

Clear either choice to compare another result. Criteria edits, cohort changes,
a new run, catalog replacement and session retirement invalidate old comparison
actions. Temporary navigation preserves a valid pair; access loss clears it.
Editing and restoring old text cannot revive a captured action.

The pair lasts for the current session. This workflow adds no stored comparison,
combined report format, provider, request route, financial formula, valuation
rank, peer classification or broader issuer coverage. Source, native, visual,
integration and publication acceptance remain separate in
[Current work](CURRENT_WORK.md). Browser work remains stopped.
