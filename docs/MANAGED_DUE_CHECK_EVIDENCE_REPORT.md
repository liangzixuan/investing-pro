# Keep a finished due-check evidence report

From a finished chosen Follow-ups review, prepare a private HTML reading copy.
Keep the original chosen order, each current authored check and its complete
retained source reading. An uncaptured check remains explicitly uncaptured.
This report adds no provider, persistence schema or imported history.

## Complete workflow

1. Load Follow-ups, choose due checks and use the existing explicit company source
   pass. Retain evidence, author assessments and return through Back. Continue
   and Finish keep their existing behavior.
2. Select **Prepare finished review report**. Inspect the full preview, including
   current assessments and the earlier authored check stored with each reading.
   The two records can differ; preparation does not rewrite either record.
3. Download the HTML in the managed browser or choose an Android document.
   Cancelling document selection preserves the prepared report and drafts.
   Clear the preview when it is no longer needed.
4. Save Follow-ups separately. Fresh Load verifies authored changes. The private
   file remains the captured reading; it cannot restore or refresh a draft.

The existing complete Follow-ups draft report keeps its all-entry scope. This
finished-review report contains only the chosen checks and their retained
company evidence. Unchosen checks and unrelated resource collections are excluded.

## Complete payload and lifetime

Preserve exact check/listing/share-class/CIK/catalog identities, questions,
assessments, due/completion dates, full Price/Annual/Filings/Interim source states,
source-pass outcomes and refusals. Keep source times, reading capture times, the
review's assessed day and report preparation time distinct. Label the original
Follow-ups saved/base versions and unsaved status. A later resource Save does not
change an already written file.

Prepare, preview, export and cancellation make no source requests, calculations
or online saves. The current finished review, evidence owner, valid Follow-ups
resource, catalog, session, route and file activity own the preparation. Replacing
any owner retires its action authority. Equal-value restoration cannot revive a
retired capture; late delivery completion cannot overwrite a newer report.

The on-screen reading uses passive source tables and lazy complete JSON
disclosures. Export materializes every disclosure, including those never opened.
The document has no scripts, forms or remote assets. Its fixed metadata uses
purpose `investment.due-check-evidence-html`, format `1`, and filename
`Investment-due-check-evidence-<compact-full-UTC-time>.html`. The existing chosen
file writer enforces strict UTF-8 and a complete 8 MiB limit. Oversized or
malformed content is refused as a whole, without truncation.
