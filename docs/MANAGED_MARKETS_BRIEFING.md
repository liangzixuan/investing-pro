# Markets daily briefing

This M1/M3 source increment connects selected reads, complete dated evidence and
an authored check. Source, native and client delivery acceptance are in progress.

## Read, keep a check and return

1. In Markets, choose the exact board histories and BLS, BEA, Fed or CPI work.
   Preview the selected Load or Refresh operations, then start the ordered pass.
   The fixed scope is three board histories and four existing public sources.
   Unselected retained packets are not labelled as checked by this pass.
2. Inspect complete source results and their independent times. Keep accepted
   empty data, retained previous packets, failures, cancellation and unattempted
   work distinct. Scheduled dates do not confirm publication. CPI item published,
   item updated, feed updated and retrieval times keep their original meanings.
3. Choose **Keep a dated check** on a loaded scheduled item or CPI headline.
   Independently choose a company from the editable Watchlist, write a question
   and UTC due date, then preview the entire cited question before Create.
   Existing limits, source ownership and initial Follow-ups load rules apply.
4. Choose **Review follow-up**. The exact check and selected source item retain
   the complete briefing for reading. Use the existing company Research and
   Back actions. Assessing or completing the owned check remains separate from
   saving the Follow-ups resource.
5. Choose **Return to Markets briefing** to inspect the original complete
   reading and selected item. This action makes no Markets source request and
   does not replace live source models with old packets. Original source clocks
   and pass outcomes remain visible. The retained reading cannot create a new
   check or issue a source request.
6. Choose **Start another briefing** to use current Markets controls. Each
   provider read still needs an explicit action. **Save follow-ups** and a fresh
   explicit Load persist only authored records; briefing packets are temporary.

## Ownership and failure behavior

The return belongs to the exact workspace, active session, catalog, chosen
source and check. Unrelated navigation, source replacement, draft replacement,
file activity and recovery retire old authority. Returning to equal values cannot
renew it. An owned result or status edit can keep the reading; changing its
question, due date or company cannot silently retarget it. Transitions consume
their authority before notifications, and reentrant callbacks must recheck the
installed state. Late source responses cannot reopen a retired reading.

A failed or stopped pass cannot dispatch later work. Every available packet keeps
its own source qualifications. Unknown times remain unknown; calendar and CPI
items are not silently deduplicated. The briefing does not infer company relevance,
released economic values, economic consensus or a market-wide freshness time.

## Scope and verification

Reuse the existing three-listing board and admitted BLS, BEA, Fed and CPI models,
validators and request budgets. No new provider, feed, dependency, saved resource,
API route, fee or deployment is part of this increment. Broader assets, general
company news, earnings/dividends and whole-market movers remain outside scope.

Focused model, workspace and UI checks cover complete content, partial passes,
exact source selection, stale ownership, Research/Back and independent saves.
A complete invented native journey must pass before client acceptance. Browser
work remains stopped. Automated evidence does not establish owner-record access,
installation, physical-phone acceptance or sustained use.
