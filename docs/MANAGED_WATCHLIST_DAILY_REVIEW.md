# Watchlist daily review

Implementation and acceptance are in progress. This workflow extends the
existing group review under **My Watchlist**. Manual filing review remains
available in the same entry.

## Choose and read

Load the Watchlist explicitly. Choose one to five exact listings in the order
you want to review, then select **Start daily review**. Starting makes no source
request. Each listing keeps its full share-class identity.

Select Price, Filings or both and preview the complete plan. The plan shows
retained evidence, missing reads, unsupported sources and sources not selected.
Run reads only the missing sources in that preview, one request at a time,
through the existing shared source access. It does not refresh retained evidence.

A failure, cooldown or Cancel stops the pass. Completed rows remain available;
later rows are not attempted. Preview again before another explicit Run. This
uses the current evidence and does not repeat completed reads. Each source keeps
its original request and completion times, window, coverage and full response.
Verified empty results remain distinct from a source that has not been read.

## Investigate and return

Choose a company and inspect its retained evidence in Research. The visit gets
independently validated Price and Filings copies. Inspect and Back make no source
request. A separate company Refresh does not replace the group's original data.

Follow-ups loads independently. The group shows each exact listing's whole
question, status and authored assessment, or explains why no current check is
available. In company Research, use the existing check attachment and assessment
tools. An observed filing can also supply a cited dated question through the
existing explicit preview and Create action. No source result completes a check.

Back returns to the same selected company and group. Notes and assessments made
within the owned visit remain in their respective drafts. Finish retains the
complete ordered reading, source outcomes and authored checks. The finished
reading has no source or Research controls. Start a new review explicitly.

Save Watchlist and Follow-ups separately. A fresh Load is also a separate action.
Source reads, inspection and Finish do not save either resource.

## Lifetime and limits

The daily group belongs to the current Watchlist membership order, full listing
identities, catalog, resource records and session. An owned Research visit pauses
source controls and preserves the group. Notes and assessments do not change its
listing ownership. Unrelated navigation or research, changed membership/order,
resource replacement, save/recovery, file activity or session retirement ends it.
Restoring the same values does not revive captured actions.

This adds no provider, source coverage, financial calculation, persistence
resource, background retry or automatic research verdict. Price and Filings
eligibility remain independent. Financial data remains partial where unsupported
or unavailable. Source acceptance, Android delivery and physical-phone acceptance
are separate; see [Current work](CURRENT_WORK.md).
