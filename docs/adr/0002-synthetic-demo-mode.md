# ADR 0002: Synthetic demo mode

Status: accepted for Sprint 0

The runnable profile uses a fictional issuer and deterministic synthetic facts. Records include generation provenance, known-time intervals, evidence pointers, content hashes, and executable rights policies.

No collector or real market/content dataset is present. Browser persistence is explicitly non-sensitive and single-user. A later production adapter must satisfy the same ports rather than bypass the domain model.
