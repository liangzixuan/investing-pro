# ADR 0041: bounded synthetic source-owned parser-quality composition

Status: Accepted and **Promoted only for exact source commit
`1d7dee56c66c1ad0f5d612603567adf2589e0930`, the clean direct single-parent
child of frozen baseline `09e76235b5683427f2dd3201aefa740bb5adb16e`.** Full
local verification, exact-source workflows, success-only version 4 evidence
retention, independent artifact inspection, and offline review passed. Cycle
2b authority, real quality, B15/V15, real-data admission, and production remain
Blocked.

## Context

Cycle 2f defines a fixed synthetic quality population of 100 documents, 1,000
facts, and 2,000 critical assertions. Cycle 2g adds a one-shot candidate
precommitment before declared-reference reveal. Those boundaries deliberately
accept caller-authored candidate observations and therefore do not establish
which parser execution produced them.

Cycle 2m separately proves one source-owned direct-Docker execution of the
original and amendment archives through two pinned engines. It binds four
fresh container lifecycles, the exact 20-fact normalization, reciprocal
lineage, cleanup, and one invocation digest, but it deliberately makes no
quality claim. The next repository-controlled blocker is the missing adapter
between these established boundaries.

## Decision

Add one private package-owned composition protocol. Its public factory accepts
only the exact sealed Cycle 2m engine descriptors and internally creates the
direct-Docker boundary. It accepts no boundary, runner, signer, key factory,
execution result, candidate observation, fact, metric, weight, exclusion,
outcome, callback, or abort/options injection surface.

The asynchronous commit operation has exactly four arguments: the frozen
Cycle 2f plan, a declared-reference digest, the original archive, and the
amendment archive. It reserves its one-shot state before validation or `await`,
snapshots every bounded input with intrinsic operations, executes Cycle 2m,
and validates the complete direct result. The synchronous reveal operation has
exactly two arguments: an opaque instance-bound capability and the declared
reference bytes. It consumes and clears state before validation. There is no
retry or reset.

Project the ten original fact versions exactly once to fixed quality coordinate
`synthetic-filing-0001`, and the ten amendment fact versions exactly once to
`synthetic-filing-0002`. Each projection maps the closed key, concept, empty
dimensions, period, unit, and value bytes without repair or conversion. Bind
the synthetic coordinate digest separately to its actual archive digest,
source-document digest, document role, observation digest, and Cycle 2m
lifecycle provenance. The outer composition separately binds the complete
source invocation. Do not fabricate, replicate, reweight,
exclude, or otherwise populate coordinates `synthetic-filing-0003` through
`synthetic-filing-0100`.

Pass the internally derived two-document candidate observation to a fresh,
unchanged Cycle 2g protocol. Commit receives only the predeclared reference
digest; reference bytes first enter at reveal. Reveal delegates to unchanged
Cycle 2g and unchanged Cycle 2f. The outer commitment binds the direct
agreement, invocation, normalization, four lifecycle receipts, both source-to-
quality mappings, plan digest, declared-reference digest, candidate-observation
digest, and candidate commitment. The outer evaluation binding additionally
binds the Cycle 2g evaluation and Cycle 2f measurement evaluation.

The exact honest result is `evaluated` with threshold outcome `not_met`: 2 of
100 documents succeeded, 98 are missing, 20 of 1,000 expected facts are true
positives, 980 are false negatives and missing, and 1,960 of 2,000 critical
assertions are silent failures. Precision `20/20` and quarantine rate `0/100`
meet their thresholds. Document success `2/100`, recall `20/1000`, and maximum
silent failures do not. The ordered failed thresholds are
`document_success_minimum`, `fact_recall_minimum`, and
`maximum_silent_critical_failures`. `not_met` is a successful protocol
evaluation, not a quality Pass and not a quarantine.

Any configuration, argument, state, mutation, execution, mapping,
precommitment, reference, capability, measurement, dependency, or binding
failure collapses to one deeply frozen value-free quarantine. It exposes no
digest, count, fact, mapping, lifecycle, or diagnostic detail.

The sole target claim is
`bounded_synthetic_source_owned_direct_docker_cross_engine_two_document_observation_precommitment_and_fixed_population_quality_evaluation_binding`.
It is accepted only for the exact source and evidence boundary below.

## Evidence and promotion boundary

The canonical version 4 acceptance record must contain exactly six ordered
outcomes:

1. `same-input-quality-evaluation-distinct-lifecycle-invocations` evaluates
   the exact input pair twice. Both results are `evaluated/not_met`; candidate
   observations, candidate commitments, and measurement evaluations are
   stable, while direct agreement, invocation, lifecycle, outer commitment,
   and outer evaluation bindings are distinct.
2. `declared-reference-digest-mismatch` commits the candidate and returns one
   consuming empty value-free quarantine when different reference bytes are
   revealed.
3. `quality-capability-replay` returns one empty value-free quarantine when an
   already consumed reveal capability is replayed.
4. `reference-content-at-commit` supplies forbidden reference bytes as a fifth
   commit argument and consumes/quarantines before Docker execution.
5. `original-archive-tamper` returns one atomic empty value-free quarantine.
6. `original-amendment-role-swap` cannot exchange the fixed source-to-quality
   coordinate roles and returns one atomic empty value-free quarantine.

## Consequences

This decision closes the bounded repository-controlled gap from a source-owned
two-document parser execution to the existing one-shot fixed-population
quality evaluator. It deliberately proves that incomplete coverage is counted
and fails the thresholds. It does not prove a representative corpus, real
parser quality, correct adjudication, threshold adequacy, external authority,
real data, B15/V15 composition, full Cycle 2 exit, or production readiness.
