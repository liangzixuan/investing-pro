# Bundled Android client

The owner approved a personal Android application sharing the existing React UI,
with this Windows PC hosting records while it is on. This outcome proves the
maintained client/build boundary. Secure phone access and shared device sessions
follow as separate product acceptance, before personal deployment.

Use the accepted a89 source as the baseline. The unreleased Previous/Next a90
candidate stays preserved in markets-home and its durable refs. This work does
not claim or reuse its interrupted validation as success.

Acceptance:

- Desktop and bundled Android entries compose the same workspace and Markets
  components. Routing adapters preserve canonical listing identity and navigation.
- Ordinary internal links use the current platform router; modified clicks,
  downloads and external links retain their normal semantics.
- The mobile build bundles all client assets and shared styles. It includes no
  Next server runtime, Node-only module, API/vault implementation or credentials.
- The initial mobile build is explicitly disconnected. Existing local-only API
  validation remains unchanged and the mobile artifact makes no application API
  requests. It must not claim a connected account or display invented prices.
- Capacitor creates a native Android application from those assets, without a
  remote server.url, cleartext transport or broad remote navigation exceptions.
- Android Back uses the app's route history; root Back follows the native exit
  behavior. Lifecycle subscriptions are cleaned up on unmount.
- Focused route/lifecycle and desktop integration checks pass. Bundled build,
  native compilation and actual device installation are separate reported facts.

This outcome does not expose the PC, change authentication, acquire provider
data, inspect private records, provision production signing credentials or change
the accepted running release. A debug APK is development evidence, not a personal
launch artifact or physical-phone acceptance.

Root owns packages, lockfile, mobile entry/build/native project and this spec.
The mobile agent owns the shared workspace/link seam and its focused checks.
Independent review covers the composed source and bundled output. Existing
release acceptance requirements remain in force; the boundary walker adds
reviewed handling for ignored Android outputs. No release acceptance is inferred
from this work.
